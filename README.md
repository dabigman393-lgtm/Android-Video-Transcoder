# ClipShrink

Offline Android app that shrinks PS5 HDR clips and normal videos to a target size (10/20/25/50 MB) for Discord. Hardware H.264 encoding via Media3 Transformer, HDR→SDR tone mapping with a brightness option, AMOLED black UI.

**Get the APK:** Actions tab → latest "Build APK" run → download `ClipShrink-apk`.
